# StepShot – приложение для создания пошаговых инструкций

**Собственный программный проект · Windows · Beta**

StepShot помогает превращать последовательность действий на компьютере в понятную инструкцию со скриншотами. Приложение записывает шаги, позволяет редактировать их и экспортировать результат.

## Что реализовано

- Захват действий пользователя и создание шагов со скриншотами.
- Редактор инструкций: заголовки, описания, порядок шагов, маркеры кликов, кадрирование снимков.
- Автосохранение и локальная библиотека инструкций на SQLite.
- Экспорт в **PDF** и **Markdown**.
- Отдельный **ASP.NET Core API** для публикации инструкций по ссылке, обновления и отмены публикации.
- Работа с локальными инструкциями без постоянного подключения к интернету.

## Технологии

`C#` · `.NET 9` · `WPF` · `ASP.NET Core` · `SQLite` · `PostgreSQL` · `Docker` · `S3-compatible storage` · `xUnit`

## Архитектура и технические решения

Проект разделён на независимые компоненты: интерфейс Windows, захват экрана, доменная логика, хранилище, экспорт документов и облачный API. Для сохранения данных используется SQLite; для развёртывания серверной части предусмотрены PostgreSQL, объектное хранилище и Docker.

При публикации инструкция отправляется в облако только по явному действию пользователя. Редактирование локальной копии не приводит к автоматической загрузке изменений.
