## 🚀 Основной проект — StepShot

**StepShot** — Windows-приложение, которое помогает превращать действия на компьютере в пошаговые инструкции со скриншотами.

**Что реализовано:**
- Захват действий пользователя и создание шагов со скриншотами.
- Редактор инструкций: названия и описания шагов, изменение порядка, отметки кликов, кадрирование.
- Автосохранение и локальная библиотека на SQLite.
- Экспорт инструкций в **PDF** и **Markdown**.
- Отдельный **ASP.NET Core API** для публикации инструкций по ссылке.

**Технологии проекта:** `C#` · `.NET 9` · `WPF` · `ASP.NET Core` · `SQLite` · `PostgreSQL` · `S3-compatible storage` · `xUnit`.

**Моя роль:** постановка задач, проектирование функциональности, управление разработкой через Codex, интеграция частей проекта и проверка реализации.

**Статус:** бета-версия. Код StepShot находится в **приватном репозитории** и не опубликован в открытом доступе. Могу рассказать о технических решениях и показать работу приложения.
